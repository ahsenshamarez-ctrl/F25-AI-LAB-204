# AI Lab 1

This folder contains my first AI lab work: a short AI timeline and a simple scholarship eligibility program.

## Run the programs
Use Python 3 and run:

```bash
python lab1_rules.py
python lab1_compare.py
```

The scholarship thresholds are made-up examples for this lab, not a real university policy. The conversational answer in the comparison script is only an example, not a response from a real AI model.
