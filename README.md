# F25 AI Lab

This repository contains my weekly AI lab work. Each week has its own folder so the task, report, code, inputs and outputs stay together.

## Folder layout

- `Week 1/` — first lab task, report, Python examples, test data and output files.
- `Week 2/` — PEAS specifications, environment classifications, stateful controller, report, test inputs and output trace.
- Future tasks will be added in folders named `Week 3/`, `Week 4/`, and so on.

Open the README inside a week's folder for its run instructions. Please check the task instructions and fill in any required student details before submitting.
